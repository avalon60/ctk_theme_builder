# CTk Theme Builder 3.3 Series

This document summarises the changes discovered in git for the tagged `3.3.x` release series.
Each section is based on the commits introduced up to the named tag.

## `v3.3.0`

- Added colour drag-and-drop support.
- Integrated harmonics swatches with the drag-and-drop workflow.
- Updated the control panel and preview panel to support the new interaction model.
- Added the `3.3` user guide.

## `v3.3.1`

- Updated the `ctkfontawesome` dependency.
- Refined icon-browser messaging and added test coverage for the icon browser.
- Refreshed supporting dependency lock/export files and small README details.

## `v3.3.2`

- Improved install and upgrade guidance.
- Refined control panel and icon browser spacing.

## `v3.3.3`

- Refined README and documentation links, including generated-upgrade and Windows path guidance.
- Tightened left alignment in the colour-mappings area of the control panel.
- Updated the `3.3` user guide and install/upgrade notes for the newer launcher and upgrade-script workflow.
- Added the video directory to `.gitignore`.

## Notes

- Every `v3.3.x` tag present in the repository has committed changes associated with it, so none were omitted.
- The `3.3.x` line is primarily focused on the new drag-and-drop colour workflow, icon-browser polish, UI spacing cleanup, and documentation refinement.
